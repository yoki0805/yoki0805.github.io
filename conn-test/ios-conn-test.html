測試設定

遊戲頁載入模式：把遊戲頁放進下方小框載入（不登入），量到頁面 load 事件（CSS 與啟動 JS 都載完）要多久；載入期間每 3 秒同時對下面的測試對象發請求，比對卡住當下其他請求是否正常。每次測試請關掉分頁、重開新的無痕分頁，第一次載入才是冷啟動。

每一輪會同時對所有網址發請求（模擬遊戲頁一打開就同時抓 CSS 與 JS）。網址會自動加上防快取參數。只量「多久收到回應」，伺服器回 403、404 也算有回應。
